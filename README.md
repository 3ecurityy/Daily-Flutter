# Flutter UI Lab

Small Flutter projects with a focus on **beautiful UI/UX**, **clean code** and **simple, solid architecture**.
Every project is a standalone app. Open its folder and run it.

## Run any project

```bash
git clone https://github.com/3ecurityy/Daily-Flutter.git
cd Daily-Flutter/projects/01_auth_screens
flutter pub get
flutter run
```

## Principles

- **Readable first:** code you can follow without a guide.
- **No unnecessary packages:** only add one when it really saves work.
- **Feature-first folders:** `core/` for shared things, `features/` for everything else.
